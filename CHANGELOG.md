# Changelog

## v1.0.0 — 2026-10-22

Initial public research release accompanying *A spatial capillary correction
for driven junction motion in double-obstacle multiphase-field simulations*.

- B2 capillary/bulk kernels, spatial correction and optional local-memory rule.
- Frozen compact initial fields and case settings for the retained comparisons.
- Project-authored Grose-Asimow reconstruction and OpenPhase insertion caller.
- Ten exported CSV datasets, figure builders, manuscript and supplement sources.
- Source provenance, integrity hashes and short release qualification.

This release packages retained results. It introduces no new production
simulation, parameter fit, accuracy claim or optimized cost comparison.
Zenodo archival DOI assignment is a separate pending publication step.
